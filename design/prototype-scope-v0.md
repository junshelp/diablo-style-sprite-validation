# 검증 프로토타입 범위 v0

- 상태: 승인
- 승인일: 2026-08-29
- 성격: 목표 설계를 폐기하지 않고 코어 재미만 검증하는 최소 수직 슬라이스

## 검증 질문

> 집에서 출발 보급을 기다리고, 위험한 필드에 직접 들어가며, 언제 귀환할지 결정하고, 회수품으로 집을 강화하는 흐름이 다시 탐사하고 싶게 만드는가?

## 플레이 흐름

1. 집의 생산 가구가 출발 보급을 계속 생산한다.
2. 사용자가 평상 또는 정전 상태를 확인하고 출발 장비를 준비한다.
3. 작은 집 화면이 긴 필드 화면으로 전환된다.
4. 사용자가 탐사자를 직접 조작해 이동, 수색, 도구 사용과 추격 회피를 수행한다.
5. 사용자가 더 깊이 갈지 물리적 회수 지점으로 돌아갈지 결정한다.
6. 정상 귀환하면 설비 부품을 확정하고, 체력이 소진되면 구조되어 미회수품을 잃는다.
7. 설비 부품으로 생산 가구를 한 번 강화하고 다음 출발을 준비한다.
8. 필드 플레이 중에도 집의 출발 보급 생산은 계속된다.

## 구현 상한

| 영역 | 검증 프로토타입 |
|---|---|
| 집 | 고정된 작은 방, 출발 보급 자동 생산, 생산 가구 1개와 1단계 강화 |
| 탐사 지역 | 한국 지하상가 1곳 |
| 필드 루트 | 입구, 모듈 6개 이내, 짧은 주 경로, 분기 1개, 종착 오브젝트 |
| 현장 상태 | 평상, 정전 |
| 대응 장비 | 손전등 1개 |
| 현장 오브젝트 | 사물함, 배전반 |
| 상호작용 도구 | 빠루, 퓨즈 |
| 엔티티 | 추격형 1종 |
| 생존 | 체력 3칸, 모든 피해 1칸, 체력 소진 시 구조, 귀환·구조 시 완전 회복 |
| 회수 | 입구 회수 지점, 종착 오브젝트의 회수 지점 |
| 보상 | 설비 부품 1종 |
| 화면 전환 | 브라우저 안에서 작은 집 모드와 긴 필드 모드를 모의 구현 |

## 필드 시간 예산

시간은 브리핑과 장비 준비, 귀환 후 정산을 제외하고 탐사자가 필드에 진입한 순간부터 회수 또는 구조될 때까지 측정한다.

| 플레이 범위 | 목표 시간 |
|---|---:|
| 조기 회수 | 3~5분 |
| 종착 오브젝트 도달 | 8~10분 |
| 모든 분기와 오브젝트 수색 | 최대 12~15분 |

이 수치는 상용 버전의 최종 밸런스가 아니라 업무 중 짧게 직접 플레이할 수 있는지 검증하기 위한 프로토타입 기준이다.

## 출발 보급 생산 주기

출발 한 번에 출발 보급 1회분을 소비한다. 생산 시간은 집과 필드 어느 화면에 있든 동일하게 흐르며, 필드 플레이 중에도 중단되지 않는다.

| 단계 | 1회분 생산 시간 | 보관 한도 |
|---|---:|---:|
| 프로토타입 시작 | 12분 | 2회분 |
| 생산 가구 1단계 강화 후 | 8분 | 3회분 |

- 새 플레이테스트는 출발 보급 2회분을 보유한 상태로 시작한다.
- 이 수치는 대기 없이 반복 플레이하면서 지속 생산과 가구 강화 효과를 검증하기 위한 압축 밸런스다.
- 상용 버전의 생산 시간과 보관량은 이 수치로 확정하지 않는다.

## 설비 부품과 첫 강화

생산 가구의 유일한 프로토타입 강화는 설비 부품 4개를 소비한다. 깊이 탐사하면 한 번에 강화할 수 있고, 조기 회수를 반복해도 진행이 누적되도록 한다.

| 회수 범위 | 설비 부품 목표량 |
|---|---:|
| 조기 회수 | 평균 1~2개 |
| 종착 오브젝트에서 회수 | 최소 4개 보장 |
| 모든 분기와 오브젝트 수색 | 평균 5~6개 |

- 종착점에 도달해 정상 회수하면 한 번의 탐사로 생산 가구를 강화할 수 있다.
- 조기 회수는 두세 번의 성공으로 같은 강화를 달성할 수 있다.
- 체력이 소진되어 구조되면 해당 세션에서 모은 설비 부품은 확정되지 않는다.
- 보상량은 프로토타입 검증용이며 상용 경제의 최종 수치가 아니다.

## 단발 추격 조우

프로토타입의 엔티티는 필드 시작부터 순찰하지 않는다. 사용자가 깊은 구역에 진입하거나 소음이 큰 현장 오브젝트를 조작하면 한 세션에 한 번만 추격 조우가 촉발된다.

1. 초반 수색 구간에는 엔티티가 등장하지 않는다.
2. 깊은 구역 진입 또는 소음이 큰 오브젝트 조작이 추격 조건을 충족한다.
3. 조명 변화와 소리로 짧은 출현 경고를 제공한다.
4. 엔티티가 탐사자를 직접 추격하며 접촉할 때 체력 피해를 준다.
5. 사용자는 공격하지 않고 시야를 끊은 뒤 캐비닛이나 셔터식 폐점포에 숨는다.
6. 엔티티가 은신처 진입을 봤다면 탐사자를 찾아내 체력 피해를 주고 밖으로 밀어내며 추격을 계속한다.
7. 엔티티가 진입을 보지 못했다면 주변을 잠시 수색한 뒤 떠나고 추격이 종료된다.
8. 은신에는 QTE나 확률 판정을 사용하지 않고 시야 차단 여부만 검사한다.
9. 은신에 성공하면 같은 필드 세션에서는 추격 조우를 다시 시작하지 않는다.

필드 루트에는 추격 촉발 전에 사용자가 위치를 확인할 수 있는 은신처를 배치한다. 이 구조는 범용 순찰·전투 AI를 구현하지 않고 `수색 → 욕심 → 공포 → 시야 차단 → 은신 → 회수 판단`의 연결을 검증하기 위한 것이다.

## 체력 규칙

- 최대 체력은 3칸이다.
- 위험한 기본 수색 결과, 엔티티 접촉과 은신 중 발각은 각각 체력 1칸을 감소시킨다.
- 엔티티에게 피해를 받으면 짧은 무적 시간과 도주 거리를 제공해 연속 피해를 막는다.
- 체력이 모두 소진되면 관리인에게 구조되고 미회수 설비 부품을 잃는다.
- 필드 안에는 체력 회복 아이템을 두지 않는다.
- 정상 귀환이나 구조로 집에 도착하면 체력은 즉시 3칸으로 회복된다.
- 이동 저하, 출혈과 같은 별도 부상 디버프는 사용하지 않는다.

## 엔티티 시야 판정

- 엔티티는 진행 방향을 기준으로 약 120도의 정면 시야를 가진다.
- 탐사자와 엔티티 사이의 벽, 기둥과 닫힌 셔터는 시야를 차단한다.
- 탐사자가 은신 동작을 시작한 순간부터 완료할 때까지 한 번이라도 시야에 들어오면 발각으로 기록한다.
- 시야가 완전히 차단된 상태에서 은신을 완료하면 엔티티는 주변을 수색한 뒤 떠난다.
- 청각, 냄새, 은신 수치와 무작위 발견 확률은 구현하지 않는다.
- 시야 원뿔은 개발 모드에서만 디버그 표시하고 실제 플레이에서는 캐릭터 방향과 연출로 전달한다.

## 현장 오브젝트와 도구 대입

- 현장 오브젝트를 조사하면 `그냥 수색`과 `아이템 사용`만 표시한다.
- `아이템 사용`을 선택하면 휴대한 상호작용 도구를 모두 보여 주며 호환 여부는 표시하지 않는다.
- 사용자는 오브젝트 하나당 도구 하나만 시험할 수 있다.
- 맞지 않는 도구는 소모하지 않지만 기본 수색이 실행되고 해당 오브젝트의 상호작용은 종료된다.
- 맞는 도구는 특수 반응을 일으키며 도구별 규칙에 따라 소모될 수 있다.
- 빠루와 사물함의 특수 반응은 추가 회수 기회와 큰 소음을 함께 발생시킨다.
- 퓨즈와 배전반의 특수 반응은 퓨즈를 소모하고 주변 조명을 복구한다.
- 환경 그래픽은 가능한 조합을 암시할 수 있지만 도구 이름이나 정확한 결과는 알려 주지 않는다.
- 프로토타입에서는 조합 발견 기록과 도감을 구현하지 않는다.

## 상호작용 UI의 시간 처리

- 현장 오브젝트 선택창이 열리면 탐사자 이동, 엔티티 AI와 필드 판정을 일시정지한다.
- 배경 애니메이션과 환경음은 계속 재생한다.
- 집의 출발 보급 생산은 실제 시간 기준으로 계속 진행한다.
- 선택을 확정하면 메뉴를 닫은 뒤 기본 수색 또는 특수 반응의 소음, 체력 피해와 회수 결과를 적용한다.
- 추격 조우 중에는 현장 오브젝트 선택창을 열 수 없다.

## 저장과 오프라인 생산

- 브라우저 로컬 저장소에 출발 보급, 설비 부품, 생산 가구 강화 여부와 마지막 저장 시각을 보존한다.
- 다음 실행 시 마지막 저장 이후의 실제 경과 시간을 계산해 출발 보급을 현재 보관 한도까지 생산한다.
- 오프라인 생산은 출발 보급에만 적용하고 설비 부품과 현장 회수품은 생성하지 않는다.
- 필드 세션의 맵, 체력, 엔티티, 현장 지도와 미회수품은 저장하거나 복구하지 않는다.
- 필드에서 앱을 닫거나 새로고침하면 다음 실행 시 집에서 시작한다.
- 중단된 출발 보급은 소비된 상태로 유지하고 미회수 설비 부품은 잃으며 체력은 3칸으로 회복한다.
- 프로토타입에서는 세이브 슬롯, 클라우드 저장과 필드 체크포인트를 구현하지 않는다.

## 의도적인 간소화

- 필드 루트는 `입구 → 모듈 3~4개 → 분기 1개 → 종착점` 수준의 제한된 조립만 사용한다.
- 현장 상태는 갱신 규칙을 구현하지 않고 출발 화면에서 평상과 정전을 직접 선택한다.
- 현장 오브젝트와 도구의 결과는 `오브젝트 + 도구 → 특수 반응`, 그 외에는 기본 수색으로 처리하는 데이터 조합표로 정의하고 승인된 두 오브젝트와 두 도구만 넣는다.
- 엔티티는 한 세션에 한 번만 행동으로 촉발되는 추격을 수행하며 상시 순찰과 전투는 구현하지 않는다.
- 관리인은 집 화면의 단일 NPC로 보이지만 상점·창고 전체 UI는 구현하지 않는다.
- 실제 운영체제 창 크기는 제어하지 않고 브라우저 안의 레이아웃 전환으로 경험을 모의한다.
- 저장은 브라우저 로컬 저장소 한 개만 사용하고 중단된 필드 세션은 복구하지 않는다.

## 이번 범위에서 제외

- 복수 탐사 지역, 지역 해금과 지역별 조사 진행도
- 침수·오염 등 추가 현장 상태와 상태 갱신 주기
- 완전한 구역 문법, 이상현상 패스, 범용 생성 검증과 시드 QA
- 중간 회수 지점 해금
- 오브젝트·도구 조합 발견 기록과 도감
- 자유 가구 배치, 생활 가구, 방 지표, 방 레벨과 물리적 방 확장
- 현금, 환금품, 준비 상점과 영구 장비 수리 경제
- 현금 상품, 영구 설비 가속 등 상용화 기능
- 복수 엔티티, 복합 상태이상과 부상 디버프
- 실제 운영체제 창 크기 제어와 데스크톱 고정 동작
- 세이브 슬롯, 클라우드 저장, 필드 체크포인트와 세션 복구

## 완료 판정

- 집에서 필드로 출발하고 귀환 또는 구조되어 다시 집으로 돌아오는 한 사이클이 끊김 없이 동작한다.
- 필드에 머무는 동안에도 출발 보급이 누적된다.
- 출발 시 보급 1회분이 소비되고, 기본 가구는 12분마다 최대 2회분까지 생산한다.
- 평상과 정전에서 시야, 대응 장비와 현장 오브젝트의 결과 차이를 체감할 수 있다.
- 현장 오브젝트에서 `그냥 수색 / 아이템 사용`만 제시하고 도구 호환 여부는 숨긴다.
- 맞지 않는 도구는 소모하지 않고 기본 수색으로 판정되며, 맞는 빠루 또는 퓨즈는 장단점이 있는 특수 반응을 일으킨다.
- 상호작용 UI가 열린 동안 필드 시뮬레이션은 정지하지만 집의 출발 보급 생산은 계속된다.
- 앱을 다시 열면 오프라인 경과 시간만큼 출발 보급이 보관 한도까지 누적된다.
- 필드에서 종료하면 다음 실행 시 집으로 돌아오고 소비한 보급과 미회수 설비 부품은 복구되지 않는다.
- 체력과 미회수품 때문에 계속 탐사할지 귀환할지 선택할 이유가 생긴다.
- 모든 피해가 체력 1칸을 줄이고, 0칸에서 구조되며, 귀환 후 3칸으로 즉시 회복된다.
- 깊은 구역 또는 소음 행동이 경고 후 단발 추격을 촉발하고, 엔티티 접촉이 체력 피해를 준다.
- 시야를 끊고 캐비닛이나 셔터에 숨으면 추격이 끝나며, 진입을 목격당하면 발각되어 체력 피해 후 추격이 계속된다.
- 은신 발각은 120도 정면 시야와 장애물 차단만으로 결정되고 확률 판정을 사용하지 않는다.
- 조기 회수, 종착점 도달과 전체 수색이 각각 정한 필드 시간 예산 안에서 가능하다.
- 조기 회수는 평균 1~2개, 종착점 회수는 최소 4개의 설비 부품을 제공한다.
- 회수한 설비 부품으로 생산 가구를 강화하면 다음 출발 준비가 빨라진다.
- 생산 가구 강화 후에는 8분마다 최대 3회분까지 생산되어 변화가 즉시 체감된다.
- 상점, 다중 지역, 방 레벨 없이도 두 번째 탐사를 시작할 동기가 발생하는지 플레이테스트로 평가할 수 있다.
