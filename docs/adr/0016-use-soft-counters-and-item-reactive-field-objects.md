# 대응 장비는 소프트 카운터로 사용하고 현장 오브젝트는 도구에 반응한다

현장 상태마다 특정 장비를 강제하면 브리핑과 준비가 전략이 아니라 정답 확인 절차가 되고, 장비가 없을 때 플레이 자체가 중단된다. 따라서 알맞은 `대응 장비`가 없어도 지역 진입과 `기본 수색`을 허용하되, 정전에서는 회수량 감소나 체력 피해 위험이 생기고 침수에서는 이동 저하·소음 증가와 일부 회수 포기가 발생하게 한다. 알맞은 장비는 이러한 불이익을 줄이는 소프트 카운터로 사용한다. 또한 다키스트 던전의 Curio 상호작용 구조를 참고해, 사용자가 빠루·열쇠·퓨즈·소독제 같은 `상호작용 도구`를 `현장 오브젝트`에 직접 사용하면 더 안전한 수색, 다른 회수품 또는 경로를 얻도록 한다. 대응 장비와 도구는 결과의 범위를 바꾸지만 최고 보상을 확정하지 않는다.
