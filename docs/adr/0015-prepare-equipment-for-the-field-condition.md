# 현장 상태를 보고 대응 장비를 준비한다

탐사 지역과 현장 상태가 보상 확률만 바꾼다면 사용자는 가장 높은 기대값만 비교하고 출발 준비는 반복 작업이 된다. 따라서 `탐사 브리핑`에서 현장 상태를 출발 전에 공개하고, 상태마다 유효한 `대응 장비`와 탐색 방식이 달라지게 한다. 정전에서는 조명과 배터리가, 침수에서는 방수 및 이동 보조 도구가 유리한 것처럼 장비 선택이 접근 가능한 경로, 위험과 회수 효율을 바꾼다. 모든 상태에 통하는 단일 장비 조합과 자동 최적 장착은 사용하지 않는다.
