# 고정 랜드마크 사이의 필드 루트를 매번 재생성한다

탐사 지역의 전체 맵을 영구 보존하면 첫 탐사 후 안전 경로와 보상 위치가 고정되어 수색과 공포가 빠르게 약해진다. 반대로 모든 공간을 새로 만들면 같은 장소를 다시 탐사한다는 감각과 정상 공간에 대한 학습이 사라진다. 따라서 `탐사 지역`의 정체성, 구역 문법과 `고정 랜드마크`는 유지하되, 랜드마크 사이의 방·통로·잠금·회수품·엔티티·이상현상으로 구성되는 `필드 루트`는 출발마다 다시 생성한다. `현장 지도`는 현재 세션에만 유지하고, 귀환 후에는 정확한 배치 대신 발견한 이야기와 이상현상을 `지역 기록`으로 보존한다.
