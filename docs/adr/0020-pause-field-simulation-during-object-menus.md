# 오브젝트 선택 중에는 필드만 정지한다

도구 조합을 고르는 동안 엔티티와 환경 위험이 계속 움직이면 사용자가 미스터리를 추론하기보다 메뉴를 빠르게 넘기게 되고, 데스크톱 컴패니언의 짧은 능동 플레이에도 불필요한 조작 압박이 생긴다. 반대로 전체 시간을 멈추면 필드에서 무엇을 하든 집의 지속 생산이 이어진다는 코어 원칙이 깨진다. 따라서 현장 오브젝트 UI가 열린 동안에는 `상호작용 정지`로 탐사자, 엔티티 AI와 필드 판정만 멈추고 배경 연출·환경음과 집의 `기초 수급`은 계속한다. 선택을 확정한 뒤 메뉴를 닫고 소음·체력 피해·특수 반응을 적용하며, 추격 조우 중에는 오브젝트 UI를 열 수 없다.
