# 부분 정보를 보고 탐사 지역을 선택한다

아무 정보 없이 절차 생성 필드에 출발하면 출발 보급의 소비와 장비 준비가 판단보다 운에 좌우된다. 반대로 완성된 지도와 보상 위치를 공개하면 수색과 공포가 약해진다. 따라서 사용자는 출발 전에 여러 `탐사 지역` 중 하나를 선택하고, `탐사 브리핑`에서 예상 규모, `현장 상태`와 주요 발견 가능성만 확인한다. 정확한 방 배치, 회수 지점 위치, 내부 생성 역할과 이상현상은 숨긴다. 진입 후에는 `현장 지도`가 실제로 확인한 공간만 기록하며, 사용자는 노드 지도를 클릭하는 대신 탐사자를 직접 조작해 `현장 분기`를 선택한다.
