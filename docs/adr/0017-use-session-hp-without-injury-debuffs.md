# 필드 피해는 세션 체력으로만 표현한다

현장 수색이나 엔티티 공격마다 이동 저하, 출혈, 수색 속도 감소 같은 부상 디버프를 추가하면 한 번의 실수가 연속된 조작 불편으로 이어져 직접 플레이의 재미를 해칠 수 있다. 따라서 필드의 피해는 한 세션 동안 유지되는 `체력` 감소로만 표현하고 별도의 부상 상태를 만들지 않는다. 체력이 소진되면 관리인에게 `구조`되며, 정상 귀환이나 구조로 집에 도착하면 체력은 대기 시간과 추가 비용 없이 전부 회복한다. 체력 감소는 더 깊이 탐사할지 회수할지 판단하게 하지만 다음 출발을 지연시키지 않는다.
