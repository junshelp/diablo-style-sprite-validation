# 필드는 생존 호러, 집은 Idle 메타 레이어로 분리한다

Idle과 익스트랙션을 같은 필드 루프에 적용하면 자동 진행과 능동적 생존이 충돌하고, 지나친 사건을 다시 처리하는 복잡한 구조가 필요해진다. 따라서 `필드`는 사용자가 명시적으로 출발해 직접 플레이하는 세션형 익스트랙션 생존 호러가 소유하고, `집`은 데스크톱에 계속 켜두며 기초 자원 생산·회복·보관·정비를 담당하는 Idle 메타 레이어가 소유한다. 필드 플레이 중에도 집의 기초 수급은 계속되며, 필드에서만 얻는 회수품이 출발의 당위성을 제공한다.
