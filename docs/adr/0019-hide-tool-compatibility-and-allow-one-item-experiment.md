# 도구 호환성을 숨기고 오브젝트마다 한 번만 시험한다

현장 오브젝트가 `빠루 사용`처럼 맞는 도구를 직접 표시하면 사용자는 조합을 발견하지 않고 정답 버튼을 누르게 되어 미스터리가 약해진다. 반대로 같은 오브젝트에 모든 아이템을 차례로 넣을 수 있으면 발견이 무제한 전수조사가 된다. 따라서 오브젝트 UI는 `그냥 수색`과 `아이템 사용`만 보여 주고, 아이템 사용에서는 휴대한 모든 `상호작용 도구`를 호환 표시 없이 선택하게 한다. 오브젝트당 `도구 대입`은 한 번만 허용하며, 맞지 않는 도구는 소모하지 않지만 `기본 수색`으로 판정해 해당 오브젝트를 종료한다. 맞는 조합은 도구 소모·소음·위험과 보상을 함께 바꾸는 `특수 반응`을 일으키며 무조건 상위 결과로 만들지 않는다.
