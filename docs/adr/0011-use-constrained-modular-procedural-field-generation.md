# 제약된 모듈형 절차 생성으로 필드 루트를 구성한다

완전히 무작위로 방을 연결하면 한국 지하상가의 공간적 설득력이 무너지고 생성 오류와 의도된 이상현상을 구분하기 어렵다. 반대로 모든 루트를 손으로 만들면 반복 탐사의 변화량과 제작 효율이 부족하다. 따라서 손으로 설계한 `방 모듈`을 `구역 문법`과 보상·위협 예산에 따라 조합해 유한한 `필드 루트`를 생성한다. 입구, 종착 오브젝트, 주요 경로와 회수 지점의 도달 가능성을 보장하고, 열쇠와 잠금의 순서 및 엔티티 경로를 `생성 검증`으로 검사한다. 정상적인 루트를 먼저 완성한 후 `이상현상 패스`가 제한적으로 공간 규칙을 깨뜨리며, 재현과 오류 추적을 위해 `생성 시드`를 보존한다. 사용자에게 아이템 방이나 엔티티 방 같은 생성 역할을 직접 표시하지 않는다.
