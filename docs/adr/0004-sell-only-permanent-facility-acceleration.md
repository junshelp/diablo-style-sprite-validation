# 시간 단축은 영구 설비 가속으로만 판매한다

출발 보급의 대기 시간을 반복해서 판매하면 적극적으로 필드를 플레이하는 사용자에게 결제 압력이 집중되고, 집의 생산 속도를 의도적으로 불편하게 조정한다는 인상을 줄 수 있다. 따라서 소모성 즉시 충전이나 임시 부스트는 판매하지 않고, 상업적인 시간 단축은 생산 가구의 속도 또는 보관 능력을 영구적으로 개선하는 `영구 설비 가속`으로만 제공한다. 기본 생산 곡선은 구매 없이도 정상적으로 플레이할 수 있도록 먼저 설계한다.

현재 프로토타입에는 현금 상점이나 유료 상품을 구현하지 않고 게임성만 검증한다. 향후 유료 생활 가구를 추가하더라도 게임 안에서 얻는 가구와 같은 성능 예산을 사용하며, 외형과 지표 조합만 다른 사이드그레이드로 제한한다.
