# 시야를 끊고 은신해야 추격이 끝난다

불이 켜진 안전 구역에 도달하기만 하면 추격이 경로 암기와 달리기로 끝나고, 복잡한 전투나 상시 은신 AI를 구현하면 검증 프로토타입의 범위를 벗어난다. 따라서 엔티티와의 `추격 조우`에서는 전투를 사용하지 않고, 사용자가 시야를 끊은 뒤 캐비닛이나 셔터식 폐점포 같은 `은신처`에 들어가야 추격이 끝난다. 엔티티가 은신 동작 중인 탐사자를 `시야 판정`으로 한 번이라도 확인했다면 `발각`되어 체력 피해를 받고 밖으로 밀려나지만 즉사하거나 연속 피해를 받지는 않는다. 진입을 보지 못했다면 엔티티가 주변을 수색한 뒤 떠나며 `은신 성공`으로 판정한다. 무작위 캐비닛 검사, QTE와 확률 판정은 사용하지 않는다.
